# Victimas_SESNSP
Este repositorio contiene una aplicación desarrollada en Shiny para R, cuyo objetivo principal es visualizar los datos de víctimas del Secretariado Ejecutivo del 
Sistema Nacional de Seguridad Pública (SESNSP).
La aplicación permite explorar visualmente los datos y fue diseñada con énfasis en la claridad, transparencia y reproducibilidad del proceso.
El repositorio está compuesto por los siguientes elementos:
1. Archivo principal de la aplicación: Víctimas_SESNSP que contiene el código fuente de la aplicación Shiny.
2. Base de datos: IDVFC_NM_2024.csv que contiene información sobre víctimas registradas en averiguaciones previas y carpetas de investigación iniciadas.
   Nota: Se optó por usar únicamente el archivo correspondiente a 2024 para evitar el ralentizamiento de la aplicación. Sin embargo, la app puede adaptarse para utilizar
   la base completa (2015–2024). Asimismo, la aplicación incluye rutinas de carga, limpieza y transformación de datos para asegurar su correcta visualización.
3. Carpeta: Capas que contiene los archivos necesarios para generar mapas dentro de la aplicación.
4. Recursos gráficos: Logo.png que es la imagen que debe ubicarse en la carpeta www dentro del directorio de la aplicación.
   Para facilitar su inclusión, se adjunta la carpeta comprimida www, que ya contiene este archivo.
5. Documentación y capturas:
5.1 Aplicación_shiny_SESNSP.docx: incluye capturas de pantalla ilustrativas del funcionamiento de la aplicación.
5.2 Deploy_api_Victimas_SESNSP.docx: documenta el problema al intentar desplegar la aplicación en línea, incluyendo capturas de pantalla.
Nota: Actualmente no está disponible una URL pública de la aplicación, ya que su publicación requiere una suscripción al plan estándar o superior.
